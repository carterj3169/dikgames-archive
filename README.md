Curated direct cloud mirror index and Android APK releases from [DikGames](https://dikgames.online/).

DikGames is an uncensored adult visual novels archive and gaming database featuring direct cloud download mirrors (Mega, Pixeldrain, GoFile, VikingFile), walkthroughs, save files, and Android APK ports.
